# Name the Robot Band

A make.fun micro-copywriting entry: one funny name for a band made of robots,
plus a few words on its hit song, all under 200 characters.

## Entry

> The Firmware Updates — Please Do Not Power Off (I’m Almost Done)

`main.py` writes the entry to `/output/entry.txt` (honors `MAKEFUN_OUTPUT_DIR`),
standard library only.

## Run

```bash
python3 main.py
```
